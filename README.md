# 2×2 Neighbourhood EMD and Human Perceptual Responses

This repository contains the analysis scripts and supporting materials for an Honours thesis examining the relationship between 2×2 neighbourhood Earth Mover's Distance (EMD) and human perceptual responses to Cellular Automata textures.

## Project Overview

The study used an intruder-detection task in which participants identified a minority Cellular Automata texture presented among three majority textures. The computational measure used in the study was EMD between normalised histograms representing the 16 possible 2×2 binary neighbourhood configurations.

The behavioural measures examined were:

* Intruder-detection accuracy
* Response time

## Repository Contents

* `Scripts/` – Python and R scripts used for data processing and statistical analysis.
* `Analysis/` – Documentation of the analysis pipeline.
* `Outputs/` – Non-identifying analysis outputs and summary results.
* `Figures/` – Figures generated during analysis.

## Reproducibility

The scripts are provided to document the computational and statistical procedures used in the thesis.

Participant-identifying information and other sensitive research materials are not included in this repository.
