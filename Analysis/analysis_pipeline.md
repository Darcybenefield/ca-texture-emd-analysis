# Analysis Pipeline

This folder contains documentation describing the data processing and statistical analysis procedures used in the study.

The analysis involved:

1. Merging and screening the experimental data.
2. Calculating Earth Mover's Distance (EMD) between majority and minority texture representations.
3. Examining the relationship between EMD and intruder-detection accuracy.
4. Examining the relationship between EMD and response time.
5. Conducting residual analyses to examine variation not accounted for by EMD.
